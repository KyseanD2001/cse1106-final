# Requirements

## Functional Requirements

FR1:
We need to be able to record when a student enters the room.

FR2:
We need to be able to record when a student leaves the room.

FR3:
We need to make sure occupancy never goes below zero.

FR4:
We need to make sure occupancy never goes above the room capacity.

FR5:
We need to display the current occupancy.

FR6:
We need to display whether the room is FULL or AVAILABLE.

FR7:
We need to save occupancy events to a CSV file.

FR8:
We need to turn on the green LED when space is available.

FR9:
We need to turn on the red LED when the room is full.

FR10:
We need to allow the user to change the room capacity.

FR11:
We need to use scanf() to receive user input.

FR12:
We need to use a loop to keep the program running until the user exits.
